# Dr. Evald — сайт стоматологической клиники

Проект содержит готовую статическую демоверсию для показа заказчику и исходники WordPress. В демоверсии 96 страниц на русском, латышском и английском: услуги, врачи, цены, блог, о клинике, контакты и информация пациентам. Сохранены оригинальный логотип, фотографии, раскрывающиеся категории прайса и поиск.

## Запуск демоверсии на Cloudflare Pages через GitHub

1. В Cloudflare откройте **Workers & Pages → Create application → Pages → Connect to Git**. Выберите GitHub и предоставьте доступ к этому репозиторию.
2. Создайте **новый Pages-проект с Git integration**. Если ранее создан проект с ручной загрузкой, он не переключается на Git integration; используйте новое имя, например `dr-evald-preview`.
3. Выберите ветку `main`. Framework preset: **None**. Корень проекта оставьте пустым.
4. Build command: **`npm run build`**. Build output directory: **`dist`**. Внешние пакеты не требуются.
5. Нажмите **Save and Deploy**. После публикации Cloudflare покажет постоянную ссылку `https://<имя-проекта>.pages.dev`.

Cloudflare автоматически передаёт адрес сборки через `CF_PAGES_URL`; сборка обновляет canonical, Open Graph и hreflang. Для собственного домена задайте переменную **`SITE_URL=https://ваш-домен`** и пересоберите проект. Изменения в ветке `main` после подключения будут публиковаться автоматически.

Это статическая копия для согласования дизайна. Формы показывают демонстрационное подтверждение и **не отправляют заявки**. WordPress-админка доступна в исходном Local, а не в Pages. Демо закрыто от индексации через robots.txt, метатеги и заголовок X-Robots-Tag.

## Локальная проверка демо

Нужен Node.js 20 или новее:

```sh
npm run build
npm run check
```

Для просмотра запустите любой статический сервер из папки `dist` (например, `python -m http.server 8080 --directory dist`) и откройте `http://localhost:8080`. Открытие HTML двойным щелчком не подходит из-за путей от корня сайта.

## WordPress

- `wordpress/theme/` — самостоятельная тема `drevald-atelier`.
- `wordpress/plugin/` — модуль `drevald-core`: SEO, языки, маршруты, врачи и заявки.
- `wordpress/migration/public-content.json` — актуальный экспорт 96 опубликованных материалов, публичных SEO-метаполей и настроек. Пользователи, пароли, черновики, заявки и база данных исключены.
- `wordpress/migration/README.md` — инструкция восстановления на чистом WordPress.
- `public/wp-content/uploads/` — используемые на сайте изображения.

Полный WordPress требует хостинга с PHP и MySQL. GitHub хранит исходники, а Cloudflare Pages обслуживает статическое демо. Изменения контента в Local не попадают в этот экспорт автоматически: после редактирования требуется обновить статические страницы и публичный экспорт.

## Состав и ограничения

`public/` содержит готовый сайт; `scripts/` — сборку и проверку. Локальные архивы, резервные копии, отчёты, данные авторизации и служебные файлы хостинга в репозиторий не включены.

На сайте семь стоматологических услуг; биоревитализация удалена, старые адреса перенаправляются. Временный портрет врача и сгенерированные иллюстрации подписаны как иллюстративные. Неподтверждённые биографии и клинические работы не выдумывались. Перед запуском для пациентов клиника должна согласовать тексты, цены, правовую информацию, фотографии и обработку обращений.

Документация: [подключение GitHub к Cloudflare Pages](https://developers.cloudflare.com/pages/get-started/git-integration/).
