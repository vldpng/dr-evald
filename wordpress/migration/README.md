# Восстановление WordPress

Экспорт `public-content.json` получен из рабочей версии Local 16 октября 2026 года. Включены только 96 опубликованных страниц, статей и профилей, их публичные метаполя, 19 используемых записей медиатеки и выбранные настройки сайта. Аккаунты, пароли, заявки, база и черновики не включены. Адрес исходной установки заменён на `https://example.invalid` и подставляется при импорте.

Используйте **новую** установку WordPress с PHP 8.2 или новее. Импорт на существующий Dr. Evald блокируется, чтобы не перезаписать ручные изменения.

1. Создайте чистый сайт в Local или на WordPress-хостинге. Создайте администратора самостоятельно.
2. Скопируйте `wordpress/theme` в `wp-content/themes/drevald-atelier`, а `wordpress/plugin` в `wp-content/plugins/drevald-core`.
3. Скопируйте содержимое `public/wp-content/uploads/` в `wp-content/uploads/` новой установки с сохранением вложенных папок.
4. Откройте **Site shell** в Local или терминал с WP-CLI в корне нового WordPress. Активируйте компоненты и импортируйте публичные материалы:

```sh
wp plugin activate drevald-core
wp theme activate drevald-atelier
wp eval-file /absolute/path/to/repository/wordpress/migration/restore.php
```

Путь в последней команде замените на реальный; на Windows заключите путь с пробелами в кавычки. Скрипт переносит изображения записей, SEO, переводы, маршруты, главную страницу и настройки первого экрана. Затем выполните `wp rewrite flush` в отдельном вызове WP-CLI, чтобы маршруты загрузились из уже импортированных настроек.

5. Проверьте главную, языки, услуги, профили врачей, цены, ссылки, изображения и формы. Экспорт JSON проверен по составу; автоматическое восстановление на отдельной чистой установке в этой поставке не выполнялось.

В отличие от статической демоверсии, WordPress-форма сохраняет заявки приватно в админке. Почтовые уведомления не настроены. Сайт после импорта остаётся закрытым от индексации; включайте её только после подготовки публичного запуска. Согласуйте с клиникой правовые тексты, цены, сведения о врачах и обработку обращений.
